# DATA-analysis--temporary_series
🧠 Task 1 – Analyse du Churn des Utilisateurs de Waze
A complete data exploration and preprocessing pipeline to understand user churn behavior, featuring:

Data cleaning & missing value imputation

Descriptive statistics & visualization (histograms, heatmaps)

Feature engineering: km_per_driving_day, professional_driver

Encoding categorical variables

Multicollinearity detection

The goal is to prepare clean and meaningful features for downstream churn prediction.

📈 Task 2 – Analyse des Séries Temporelles
Focused on the daily minimum temperatures dataset, this section includes:

Time series preparation and cleaning

Visualization of trends and seasonality

Decomposition into trend, seasonal, and residual components

Moving averages (7 & 30 days)

Autocorrelation analysis and stationarity test (ADF)
